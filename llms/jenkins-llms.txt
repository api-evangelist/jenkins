# Jenkins

> Jenkins is the leading open source automation server that enables developers to reliably build, test, and deploy software. It exposes a machine-consumable Remote Access API for nearly every resource it manages, available in XML (with XPath filtering), JSON (with JSONP), and a Python-compatible variant, secured with HTTP Basic auth using API tokens.

This file is generated by API Evangelist from the catalog entry at https://github.com/api-evangelist/jenkins. Jenkins does not publish its own llms.txt.

## APIs

- [Jenkins Remote Access API](https://www.jenkins.io/doc/book/using/remote-access-api/): Append /api/json, /api/xml, or /api/python to any Jenkins resource URL to trigger builds, read job/build information, and inspect the queue and agents.

- [MCP Server plugin (official)](https://plugins.jenkins.io/mcp-server): Jenkins acts as an MCP server at /mcp-server/mcp (streamable HTTP); exposes tools like getJob, triggerBuild, getBuild, getBuildLog, whoAmI.
