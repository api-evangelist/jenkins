Jenkins core stopped supporting Windows Server 2019 container images in Jenkins 2.569 and Jenkins 2.568.1. It is now time to drop Windows Server 2019 container images for the inbound agent container images and the SSH agent container images. Effective August 21, 2026, the Jenkins project will no longer deliver container images based on Windows Server 2019.
